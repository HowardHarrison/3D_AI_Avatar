# Presenter source

Author `presenter.blend` in this folder. The repository ships a generated placeholder GLB until that file exists.

`versions/` holds timestamped recoverable copies created by
`blender/scripts/common.py` → `save_versioned_blend()`. Those `.blend` backups
are gitignored; only `.gitkeep` is tracked.

Do not commit secrets, scanned photos of real private individuals without rights, or huge texture packs into this directory.
